# Platform install manifest — SberDS installs this on top of the py312-gpu image.
#
# Probe-verified facts about that image (deploy/probe_node, log 2026-08-13):
#   * torch 2.8.0+cu128 is PREINSTALLED and works (plus flash-attn and the full
#     nvidia-*-cu12 wheel set). NEVER pin torch here: the sber-pytorch mirror
#     also carries +xpu builds, and for an equal version PEP 440 ranks
#     "+xpu" above "+cu128", so a bare `torch==X` pin replaces the working
#     CUDA build with an Intel XPU build that dies on `import torch`
#     (ImportError: libsycl.so.9 — the first deployment crash).
#   * NVIDIA driver 570.86.15 = CUDA 12.8 ceiling. CUDA-13 wheels (cu13) can
#     never initialize on it — the JAX GPU stack below is pinned to cu12.
#   * numpy/pandas/pyarrow/tqdm/psutil are pinned to the IMAGE versions so pip
#     leaves them in place (the platform pywrapper runs in the same
#     interpreter and uses pandas itself — upgrading it underneath is a risk).
#
# Local development does not use this file: see README.md (uv + pyproject).
